# ✨ Random Quote Generator

## Description

A simple Random Quote Generator built using HTML, CSS, and JavaScript that displays inspirational quotes with a button click.

## Purpose

The purpose of this project is to practice JavaScript functions, arrays, objects, DOM manipulation, and event handling by building an interactive web application.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Display random inspirational quotes
- Show the author's name
- Generate a new quote with a button click
- Avoid displaying the same quote twice in a row
- Simple and responsive user interface
- Attractive gradient background

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click the **New Quote** button to display a random quote.
